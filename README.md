# Nabta Updates

Dépôt public des bundles de mise à jour à distance de l’application Android Nabta.

- `manifest.json` annonce la version disponible et son empreinte SHA-256.
- `bundles/<version>.zip` contient uniquement les fichiers web compilés.
- Les données du jardin restent exclusivement sur l’appareil de l’utilisateur.

Les changements natifs Android continuent de nécessiter un nouvel APK.
